# Tennis for Herdr

A layout for the [Herdr app](https://herdr.dev): your coding agents play tennis while they work. Four courts: hard, grass, clay and indoor.

![Tennis](preview.png)

## Install

Ask your coding agent:

```
Read ~/.config/herdr-app/AGENTS.md, then add this layout: https://github.com/eduardafa/herdr-tennis
```

Or copy `layouts/`, `mods/` and `themes/` into `~/.config/herdr-app/`, then switch to it with `ctrl-shift-l`.

## Use

- Pick a court with the Hard, Grass, Clay and Indoor buttons on the scoreboard, or a tennis theme in Settings.
- Click a player to jump to that agent.

What each animation means is in [RECIPE.md](RECIPE.md).
